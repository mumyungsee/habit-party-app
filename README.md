# 습관파티 — 팀으로 함께하는 30일 챌린지 앱

혼자 하는 습관은 작심삼일이지만, 같이 하면 끝까지 갑니다.

5인 1조 팀이 매일 미션을 체크하고, 같이 보는 대시보드로 서로를 응원하는 30일 챌린지 웹앱입니다. "혼자 가면 지치는 길을 친구들과 함께"라는 생각에서 출발했습니다.

## 어떻게 동작하나요

- **팀(파티) 단위 미션** — 5인 1조로 묶여 매일 자기 미션을 인증합니다.
- **같이 보는 대시보드** — 누가 했는지 한눈에 보이고, 팀 전원이 완주한 날엔 불꽃이 켜집니다.
- **응원의 순간** — 인증할 때마다 작은 축하가, 팀 전원 완주엔 큰 폭죽이 터집니다.
- **가입 없이 시작** — 이름 선택 + 핀 4자리면 끝. 무거운 회원가입 없이 바로.
- **홈 화면 앱 설치(PWA)** — 카톡 링크로 들어와 폰 홈 화면에 앱처럼 설치할 수 있습니다.

## 만든 이야기

AI 학습스터디 23기의 30일 챌린지를 위해 바이브코딩으로 만들었습니다. 거창한 기능보다 "팀이 매일 체크하고 같이 본다"는 한 가지에 집중한 MVP입니다.

## 구조 (개발자용)
- `index.html` / `style.css` / `app.js` — 화면·로직
- `data.js` — 데이터 레이어 (구글시트 Apps Script 연동)
- `apps-script/Code.gs` — 백엔드 (구글시트에 붙는 Apps Script, 배포 코드)
- `apps-script/셋업가이드.md` — 시트·배포 셋업 방법

## 데이터
구글시트 = DB. 시트 2탭:
- `members`: id|name|team|role|mission|emoji|pin (사람들이 자기 역할 줄에 이름 적음)
- `checkins`: memberId|name|day|date|done|memo|updatedAt (인증 시 자동 적재)

## 신분
이름 선택 + 핀 4자리 (처음 설정, 시트 저장). 가입·이메일 없음.

## 로컬 테스트
```
python -m http.server 8123
# → http://localhost:8123
```
(file:// 로 열면 CORS로 시트 연동 막힘 → 서버나 호스팅 필요)
