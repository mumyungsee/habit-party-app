습관파티 운영 도구

휴대폰·다른 노트북에서도 이 주소를 열면 돼.

1. 참가자 화면 테스트

실제 앱과 같은 화면, 별도 가상 명단과 저장 공간이야. 테스트01을 선택해 처음 사용할 비밀번호 4자리를 정해줘. 다른 기기에서도 같은 이름과 비밀번호로 들어가면 돼.

테스트 앱 열기 →

로그인 → 오늘 인증 → 새로고침 → 다른 기기에서 같은 기록 확인 → 인증 취소까지 시험할 수 있어. 자동 점검은 별도 계정을 사용해.

2. 연결·저장 자동 점검

문제가 생겼을 때 버튼 하나로 Google 테스트 서버의 읽기·PIN 확인·저장·재조회를 확인해.

3. 실제 참가자 진행 상황

운영 기록을 읽기만 해. 이 화면에서는 참가자의 PIN이나 인증을 바꿀 수 없어. 별도 관리자 로그인으로 보호된 화면은 아니므로 참가자방에 운영 도구 링크를 공유하지 않아도 돼.

안내

테스트 앱에는 테스트 표시가 있어. 여기서 누르는 인증은 실제 파티 진행률에 들어가지 않아. 실제 참가자 명단에 운영자를 추가할 필요 없어.

테스트에 실제 이름·개인정보·중요한 메모를 넣지 마. 가상 데이터용 환경이야.
